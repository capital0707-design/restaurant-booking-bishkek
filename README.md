# Бронирование ресторанов в Бишкеке

Веб-приложение для бронирования ресторанов в Бишкеке.

## Технологии
- HTML/CSS/JS
- Supabase (PostgreSQL + REST API)

## Функции
- Фильтр ресторанов по типу мероприятия, количеству гостей, району, среднему чеку
- Детальная информация о ресторане
- Калькулятор стоимости
- Онлайн-бронирование
